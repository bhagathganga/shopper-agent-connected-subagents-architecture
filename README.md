# Agentforce Shopper Agent with Connected Service Agents — Reference Architecture

A reusable, anonymised reference architecture for a B2C Commerce shopper agent:

- a **Product Expert** commerce subagent for product discovery and product Q&A
- **connected agents** for order support and site FAQ
- live-agent escalation
- how context is shared across agent boundaries
- how a shopper moves seamlessly between service and commerce, in both directions
